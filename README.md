# nixpkg-photocraft

Nix package for [ArtCraft PhotoCraft](https://github.com/storytold/photocraft), using its official Linux x86_64 release archive. The package installs the app directly; it does not include the ArtCraft launcher or provide an auto-updater.

Pinned upstream release: `v0.14.0`.

```sh
nix build
nix run
```
